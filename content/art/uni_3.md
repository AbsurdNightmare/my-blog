终于！我要来聊一聊关于实习的具体方法论了。

这篇主要针对的是工科尤其是计算机专业的同学，如果你是其他专业的同学可能就没有那么大的参考价值，不过我个人认为也是值得一看的。

> 还是来一个“免责声明”：本人也还没开始实习甚至面试，我就单纯想在博客聊一聊，我的建议仅供参考。

# 0. 从简历入手

我们先从一份简历的内容入手讨论一下：
- 基本的个人信息，包括姓名，常住地，求职岗位，邮箱，github链接等等；
- 校园经历，包括升学路线，GPA，修读的课程等等；
- 实习经历，包括所在的公司，担任的职务，所做的事务等等；
- 项目经历，包括做的是什么，负责什么，技术栈，解决的问题等等；
- 个人性格或者更多的能力，包括兴趣爱好，性格特点，获奖记录等等。

从上到下聊一聊吧。

# 1. 个人信息

这部分最重要的就两点：求职岗位和 Github（没有的话不用）。

## 求职岗位

明确求职岗位是一件很重要的事情。因为简历的篇幅是有限的，HR 的耐心也是有限的，所以必须在简历中尽可能简练地展示和求职岗位关联度最高的内容。

你想求职后端开发岗，就得展示你做的比如商城系统、分布式网盘等后端开发类项目；如果你是投递 AI Infra 岗，那自然就该展示 RAG，AI Agent相关的项目经历。我们总会说“专业对口”就是这样，对口才能获得更好的机会。

然后还有一小点，就是岗位有些是很具体的名字，而非简单的“后端开发”，在投递的时候要注意。

## Github

如果是计算机专业的学生，如果你现在没有 Github 的账号，那请立刻马上打开新的标签页去创建一个。很多人把 Github 想的太高端了，觉得说放在上面的都是一些大佬的作品。并不是。很多时候你做的一些测试，一些 idea，一些课设全都可以传到上面去。它就是一个仓库，一个存放你代码的地方，不要把它神化了。

当然，如果要我形容，我觉得是程序员的记忆胶囊。记录的不只是一个个项目，更是自己代码水平与能力的提升之路，不觉得这很浪漫吗(bushi)。

说回来，在没有毕业之前，可能我们做的都只是一个简单的课设，实现一些不是很难的功能。但是本科生不就是这样吗，难道要我们本科就写出什么“惊天地泣鬼神”的高级项目吗？不过，我觉得在现在的 AI 加持下这都是有可能的，只是我们讨论 Github 的话，就没必要说，写出一个多高级的才放到上面去。就像我这个简单的博客我也丢到 Github 了啊。

# 2. 校园经历

首先说一下我对升学的看法。由于本人对于学术研究没有兴趣，并且希望早点出来赚钱，所以我是从没考虑也没从研究过考研的。我认为在现在这个日新月异的互联网世界，你考不考研都要一直学习新技术。至于“考研出来工资高”这种论调，我只能说看能力，如果本身也就没什么能力，那你读完研究生也不会有赚那么多的能力。

这一块，我只想说一嘴关于 GPA 的事情。

可能大家都或多或少见过各种简历上面的“3.8/4.0”，觉得绩点在求职中也是至关重要的一环。我曾经也被骗过，后来发现那个地方你想填多少就填多少。

绝大部分的公司都是不会去查你的 GPA 那里是真是假，甚至越垃圾的公司才会越在意这些没啥用的东西。GPA 高就说明你的能力强，你的项目更高级，你可以不用 AI 吗？别搞笑了。在这个GPA 4.0照样比不上 AI 一半的现代社会，GPA 这东西就是别挂科就好了。请记住，学校最大的作用就是让你拿到毕业证和学位证，靠着学校 title 可以在就业市场混的更好。但这个是高考的事情，不是大学生要管的事情。

所以，如果你是一个只想本科就业，想早点实习的人，那请放下没用的 GPA，早点去学做项目吧。
