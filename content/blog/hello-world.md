这是这个博客的第一篇文章。

## 为什么要有这个博客

理由其实很俗套：**学过的东西不写下来，就等于没学过。**

看过的文档、调通的代码、想明白的道理，如果不落到纸上，过几个月就只剩下一个模糊的印象
"我好像在哪见过这个问题"。写下来，至少能让未来的自己少走一次弯路。

顺便也当作一个公开的笔记本 —— 如果哪篇文章能帮到别人，那更好。

## 打算写什么

- 后端开发和系统设计的学习笔记
- 踩过的坑，以及最后是怎么爬出来的
- 读书笔记和一些与技术无关的想法

## 这个站点是怎么搭的

用 [Hugo](https://gohugo.io/) 加上 [Ladder 主题](https://github.com/guangzhengli/hugo-theme-ladder)，
源码放在 GitHub，推送后由 GitHub Actions 自动构建并发布到 GitHub Pages。

写文章就是在 `content/blog/` 下新建一个 Markdown 文件，没有任何数据库或者后台要折腾。

那么，就从这里开始吧。
